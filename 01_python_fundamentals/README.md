# Python Basic Course

A beginner-friendly collection of Python examples created while learning the fundamentals of the language. Each file focuses on one core concept and contains short, practical code with comments and output demonstrations.

## Topics Covered

- Strings and string indexing
- Common string methods
- String formatting with `.format()` and f-strings
- Operators and order of operations
- Mathematical functions using the `math` module
- Conditional statements
- Lists and list operations
- `for` and `while` loops
- Loop control with `break` and `continue`
- Tuples and ranges
- List comprehension
- Sets and set operations
- Dictionaries and dictionary methods
- Dictionary comprehension

## Getting Started

### Prerequisites

- Python 3 installed on your computer
- A code editor such as Visual Studio Code
- Git, if you want to clone the repository

### Clone the Repository

```bash
git clone https://github.com/newaz-dev/python_basic_course.git
cd python_basic_course
```

### Run an Example

```bash
python 01_python_fundamentals/01_string.py
```

On some systems, use `python3` instead:

```bash
python3 01_python_fundamentals/01_string.py
```
